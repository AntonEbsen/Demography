# Archived Projects

This directory contains legacy research projects and websites that are no longer under active development but are preserved for reference and reproducibility.

## Contents

- `portfolio/`: The original "Cost of Quality" research website (British Factory Acts project).
- `exam_project_legacy.zip`: Compressed archive of the early-stage British demography analysis.
