# Stata to Python Translation

This directory demonstrates proficiency in cross-language econometric implementation by translating standard Stata demographic routines into Python.

## Scope

- **Panel Models**: Reimplementing `reghdfe` functionality using `linearmodels` and `statsmodels`.
- **Life Tables**: Converting Stata survival analysis scripts into Python using `lifelines` and `pandas`.
- **Data Harmonization**: Translating `.do` files that clean complex archival data into repeatable Python functions.

## Rationale

Translating legacy Stata code ensures research reproducibility in modern data science environments and allows for the integration of advanced visualization tools like GeoPandas and Plotly.
