# Changelog

All notable changes to the "Iron and the Altar" research project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-05-01
### Added
- **Digital Monograph**: Launched the high-fidelity Astro-based research monograph.
- **Econometric Suite**: Modularized Python package (`exam_project2`) with DiD and Event Study specifications.
- **Transparency**: Added `CITATION.cff`, `REPRODUCIBILITY.md`, and `codemeta.json`.
- **Infrastructure**: Configured GitHub Actions CI/CD (Pytest, Ruff, MyPy).
- **Interactive Tools**: Implemented the Prussian County Explorer, Hajnal Line Map, and Tension Meter.
- **Documentation**: Added comprehensive READMEs to all 20+ subdirectories.

## [0.0.5] - 2026-04-20
### Added
- **Data Harmonization**: Completed the harmonization of 50 years of Galloway VIT files.
- **Spatial Data**: Integrated 1871 Prussian county shapefiles.

## [0.0.1] - 2026-04-10
### Added
- **Initialization**: Project repository established and raw archival data uploaded.
