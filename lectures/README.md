# Course Lectures

This directory contains notes, materials, and assignments for the **MSc Economics - Demography** course at the University of Copenhagen.

## Content

- `materials/`: Lecture slides and reading lists.
- `notes/`: Personal synthesis of core demographic theories (Malthusian models, Quantity-Quality trade-offs, etc.).
- `assignments/`: Weekly problem sets covering mortality tables, fertility measures, and migration analysis.

## Context

These materials provided the theoretical foundation for the research projects hosted in this repository, particularly the focus on institutional shocks and long-run demographic transitions.
