# Interactive Components

This directory contains the custom Astro components that power the digital research monograph.

## Key Components

- `CountyExplorer.astro`: Interactive SVG charting for regional fertility trajectories.
- `PrussiaMap.astro`: Stylized SVG map for exploring provincial Catholic shares and fertility decline.
- `Timeline.astro`: Interactive legislative history with integrated data impact badges.
- `HajnalMap.astro`: Visualization of the "Hajnal Line" and Prussia's demographic straddling.
- `TensionMeter.astro`: Interactive quote-comparison tool (Bismarck vs. Vatican).
- `SpecCurve.astro`: Robustness visualization showing treatment effect stability.

## Styling

All components follow the "Imperial Dark" design system (`#0b0c0e` background with Gold/Crimson accents) and utilize the global CSS tokens defined in `Layout.astro`.
