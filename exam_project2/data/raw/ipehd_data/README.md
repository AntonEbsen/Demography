# iPEHD (Becker-Woessmann) Data

This directory contains the replication data for the **ifoSparrow / iPEHD** project, specifically used for the Becker & Woessmann (2009) study on Protestantism and human capital.

## Contents

- `ipehd_1849_indu_trans.csv`: Mid-19th century industrialization metrics (steam engines, factory workers) used as controls for pre-Kulturkampf economic development.
- `ipehd_qje2009_master.dta`: The master cross-sectional file for 1871, used for secondary validation of the Catholic share and education levels.

## Usage

These files provide critical "pre-treatment" controls to ensure that the fertility decline we observe during the Kulturkampf is not simply a proxy for industrialization or baseline human capital differences.
