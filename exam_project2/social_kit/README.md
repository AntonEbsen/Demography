- `preview.png`: High-fidelity social preview image (OpenGraph) featuring the "Iron & Altar" theme.
- `POST.md`: Drafted LinkedIn/X post with project highlights and tech stack details.

When sharing the [Digital Monograph](https://AntonEbsen.github.io/Demography/kulturkampf), use these assets to ensure high-fidelity previews and consistent academic branding.
