# Analysis Outputs

This directory is the automated destination for all regression tables, plots, and statistical logs generated by the research pipeline.

## Contents

- `figures/`: High-resolution PNG/PDF exports of event studies, trajectories, and spec curves.
- `tables/`: LaTeX and CSV exports of main regressions and robustness checks.
- `logs/`: Execution logs from the `src.analysis` package.

## Generation

Files in this directory are generated by the notebooks in `notebooks/` and the modules in `src/analysis/`.
