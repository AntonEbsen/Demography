# Notebooks

This directory contains Jupyter notebooks for exploratory data analysis and final research presentation.

## Main Notebooks

- `01_data_and_eda.ipynb`: Covers raw data inspection, population interpolation, and initial descriptive statistics.
- `02_main_analysis.ipynb`: Executes the primary DiD regressions, event studies, and robustness checks using the modular `src` package.

## Usage

To run these notebooks locally, ensure you have installed the package dependencies:
```bash
pip install -e "./exam_project2[dev]"
```
Alternatively, use the **Binder** link in the root README to run them in the cloud.
