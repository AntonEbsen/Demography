# Raw Data Sources

This directory contains the original datasets used for the analysis.

## 📊 File Descriptions

### Census Data (Excel)
- `PopulationsPast_census_data_1851.xlsx`: Census variables for 1851.
- `PopulationsPast_census_data_1861.xlsx`: Census variables for 1861.
- `PopulationsPast_census_data_1871.xlsx`: Census variables for 1871.
- `PopulationsPast_census_data_1881.xlsx`: Census variables for 1881.

These files include registration-district level data for fertility (TFR), infant mortality (IMR), and occupational structure (textiles, agriculture, etc.).

### Spatial Data (GeoJSON)
- `data1851_0.geojson`
- `data1861_0.geojson`
- `data1871_0.geojson`
- `data1881_0.geojson`

These files contain the digital boundaries for the British Registration Districts corresponding to each census year.

## 📚 Data Provenance
All data in this directory is sourced from **Populations Past**.

> Satchell, A.E.M., Shaw-Taylor, L.M.W., Wrigley, E.A., Kitson, P.M., and Newton, G.H. (2018). *Populations Past: Atlas of Victorian and Edwardian Population History*. [online] University of Cambridge. Available at: [https://www.populationspast.org](https://www.populationspast.org)
