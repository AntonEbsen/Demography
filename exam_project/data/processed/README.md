# Processed Data

This directory is intended for intermediate and final datasets generated by the analysis pipeline.

## ⚙️ Pipeline Role
The analysis in `notebooks/exam_project.ipynb` performs the following steps to generate processed data:
1. **Cleaning**: Handling missing values in census variables.
2. **Merging**: Joining Excel-based census figures with GeoJSON-based boundary files.
3. **Panel Construction**: Combining decade-level census snapshots into a single longitudinal dataframe for DiD analysis.

## 💾 Saving Data
Users are encouraged to save major intermediate outputs (e.g., the final merged panel) here as `.csv` or `.pickle` files to speed up subsequent analysis sessions.
