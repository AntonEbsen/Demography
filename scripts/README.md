# Utility Scripts

This directory contains standalone scripts for repository maintenance and automated research tasks.

## Scripts

- `generate_report.py`: Utility for filling LaTeX templates with current regression results.
- `data_fetcher.sh`: (Optional) Script for pulling raw archival updates from remote sources.
- `lint_check.sh`: Local wrapper for Ruff and MyPy static analysis.

## Usage

Scripts are intended to be run from the repository root using the `Makefile` commands or direct execution.
