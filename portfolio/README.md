# Professional Web Portfolio

This directory contains the source code for the primary research portfolio website.

## Tech Stack

- **Framework**: Astro (Static Site Generator).
- **Styling**: Vanilla CSS with a focus on high-fidelity academic aesthetics.
- **Deployment**: GitHub Pages.

## Relationship to Projects

This portfolio acts as the "Central Hub" that links to the independent research monographs (like the Kulturkampf site) and provides a broader overview of the author's research competencies and PhD quest.
